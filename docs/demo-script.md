# Three-minute demo

1. **Problem (20 seconds):** specialist data creators struggle to package paid access for AI teams. Buyers need useful samples, explicit terms, and predictable access.
2. **Discover (25 seconds):** search for Marathi, preview two original records, explain the expected behavior and versioned terms.
3. **Purchase (40 seconds):** sign in with Mera on a stable hostname. Approve the token amount and purchase. Show the actual Monad testnet transaction and issued permit. For a credential-free demo, explicitly call this a local simulation and use demo credits.
4. **Access (25 seconds):** retrieve records from the gateway and show the decrementing request allowance. Download the retrieved collection.
5. **AI workflow (30 seconds):** in live mode, show the Qwen procurement tool trace and response evaluation. In demo mode, show the manual rubric and explain that AI is not called.
6. **Revocation (25 seconds):** revoke, repeat access, and show denial. Explain that previously retrieved records cannot be recalled.
7. **Settlement evidence (15 seconds):** show actual indexed Envio purchases/revocations when the indexer is deployed.
